# CYBORG-X — Techfest Web Development Task 1

A futuristic cyborg-themed responsive landing page built with:
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- Cyberpunk/cyborg visual design
- Responsive navigation with mobile menu
- Animated hero section
- CSS-generated futuristic core
- System cards with hover effects
- Protocol section with scanner animation
- Animated statistics counters
- Interactive "Request Access" terminal
- Smooth scrolling
- Responsive layout for mobile/tablet/desktop

## Run
Open `index.html` directly in a browser.

No backend or build tools are required.
